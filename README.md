# cp-library

AtCoder（C++）用の自作ライブラリです。

AtCoder の生成AI対策ルールでは、コンテスト前に生成AIを使って作成したコードを使う場合、コンテスト開始前に Web 上に公開し、提出に参照 URL を付けることが求められています。このリポジトリはそのための公開場所です。

## 構成

- `template.hpp` — すべての解答の先頭に入れているテンプレート（マクロ・入出力ヘルパ）
- `ds/` `graph/` `string/` `math/` `geom/` `misc/` — ライブラリ本体

ライブラリのコードは `template.hpp` のマクロ（`ll`, `rep` など）と AtCoder Library を前提にしています。
`// @nopaste` の付いた行は単体でコンパイルを確認するためのもので、実際の提出には含めていません。
